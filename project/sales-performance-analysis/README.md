# Sales Performance Analysis

## Overview
This project analyzes sales data to identify trends, top-performing products, regions, and categories.

## Objectives
- Analyze sales performance
- Identify top-selling products
- Compare regional performance
- Analyze sales trends over time
- Compare different product categories

## Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook / VS Code

## Project Structure

- `sales_analysis.py` - Main analysis code
- `sales_data.csv` - Sales dataset
- `Figure_1.png` - Sales visualization
